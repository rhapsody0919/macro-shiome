# screens — macro-shiome

作成: 2026-08-16 / SDD Step 1 (UI 案件)

`docs/spec.md` の機能要件に対応する全画面。認証が無く (spec 2 節「やらないこと」)、
機能もダッシュボードに集約されるため、画面数は少ない。

## 画面一覧

| ID | 画面 | 役割 | 対応要件 |
| --- | --- | --- | --- |
| S-1 | ダッシュボード | 全指標を 1 ページに集約。期間フィルターが全要素に効く | F-2〜F-8 |
| S-2 | 利用規約・出所 | FRED 規約が課す必須表示とデータ出所の明記 | F-11 |
| S-3 | エラー画面 | データ取得不能時のフォールバック | — |

S-1 を単一ページに集約するのは、F-6 が「全チャートと相関サマリーが同一の期間範囲を参照する」ことを
要求しており、タブやページで分けると期間状態の同期漏れが起きやすいため。

## S-1 ダッシュボード

全指標の推移と相関を一望する画面。ページ上部の期間フィルターが下の全要素に適用される。

### C-1 ヘッダー

期間フィルターと鮮度表示。

- 主要素: 期間切り替え (1 年 / 3 年 / 5 年 / 全期間)、最終更新日時、欠測バッジ
- 欠測バッジは直近週にデータが無い場合に出す (FactSet 休刊週・取得失敗)。理由を区別して表示する
- 期間フィルターの選択は URL に反映し、リロードしても維持する

### C-2 相関サマリー Card (F-5)

S&P 500 指数と Forward 12M EPS の相関係数。

- 主要素: 直近半年 / 直近 1 年 / 全期間の相関係数、各期間の標本数 n
- **n < 10 の期間**: 数値を出さず「データ不足 (n=X)」と表示する
- **蓄積直後**: 全期間が n < 10 なら Card 全体を「蓄積中」表示にする
- 期間フィルターとは独立に 3 つの窓を常に表示する (この Card だけはフィルターに追従しない)。
  理由は「直近半年 / 1 年 / 全期間の比較」自体が Card の目的のため。**画面上でその旨を明記する**

### C-3 Chart 1: 指数 vs EPS (F-2)

左軸に指数、右軸に EPS 2 系列の二軸折れ線。

- 主要素: 指数切り替え (S&P 500 / NASDAQ-100)、指数の折れ線、Forward 12M EPS、Trailing 12M EPS
- EPS は導出値 (指数 ÷ PER) である旨をチャート内に常時表示する
- **NASDAQ-100 を選んだ場合**: Forward EPS の系列が存在しない (spec D-17)。凡例から消し、
  「NASDAQ-100 は Forward PER の無料取得経路が無いため Trailing のみ」と注記する
- **NASDAQ-100 の期間制約**: PER は蓄積開始以降しか無い。1 年 / 3 年 / 5 年を選ぶと EPS 系列が
  部分的または全面的に空になる。指数の線だけを描き、EPS 側は「蓄積中 (YYYY-MM-DD 以降)」と注記する
- **欠測週**: 線を繋がない。前方補完しない

### C-4 Chart 2: Forward P/E と基準線 (F-3)

S&P 500 の Forward 12M P/E と、5 年平均・10 年平均の基準線。

- 主要素: Forward P/E の折れ線、基準線 2 本、現在値、基準線の値と取得時点
- 基準線は毎週 FactSet PDF から取得した最新値。**固定値ではない**旨と取得日を表示する
- 現在値が基準線の上か下かが一目で分かること (色分けなど)
- **S&P 500 専用**。C-3 で NASDAQ-100 を選んでいても本チャートは S&P 500 のまま。その旨を明示する
- **5 年より前の期間**: バックフィルが 5 年分のため、「全期間」でも 5 年より前は空になる

### C-5 Chart 3: イールドスプレッド (F-4)

株式益回り − 10 年債利回り。

- 主要素: スプレッドの折れ線、ゼロ線、計算式の明示 (株式益回り = 1 ÷ Forward P/E × 100)
- 単位は % に統一。小数表記と混在させない
- **Forward P/E が欠測の週**: スプレッドも算出不能。線を繋がない
- 内訳 (株式益回り / 10 年債利回り) を副系列として出すかは U-S1

### C-6 追加指標チャート (F-7)

VIX・USDJPY・10 年債利回りの単体チャート 3 枚。

- 主要素: 各指標の折れ線
- 期間フィルターが効く
- FRED 由来で著作権制限が無い系列のため、欠測はほぼ起きない想定。取得失敗時は空状態を出す

### C-7 PCE チャート (F-8、P3)

- 月次データである旨を明示し、週次系列と同一チャートに混在させない
- v1 に含めるかは spec U-6 で未確定

### C-8 フッター: 出所・免責 (F-11)

- FRED 必須文言: `This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis.`
- 各指標の出所 (S&P Dow Jones Indices / Nasdaq, Inc. / FactSet / stockanalysis.com / FRB / CBOE) と著作権表示
- **EPS / PER が as-reported (GAAP) ベースである旨**。一般的な投資レポート (operating ベース) とは
  約 9% ずれるため、誤読を防ぐ注記を入れる
- **NASDAQ-100 の PER は ETF (QQQ) 由来**で指数そのものの PER と厳密には一致しない旨
- S-2 へのリンク
- 投資助言ではない旨の免責

## S-2 利用規約・出所

FRED 規約が「他ユーザー向けアプリ」に課す義務を満たすための静的ページ (F-11)。

- FRED API Terms of Use へのリンクと、「本アプリの利用により FRED API 規約に同意したことになる」旨
- 各データソースの出所・著作権・利用条件
- stockanalysis.com は規約が出所明記を条件にスニペット利用を認めているため、出所を明記する
- 権利者からの要請時に系列単位で公開停止する運用方針 (spec U-8)
- 文面は U-S2 で未確定

## S-3 エラー画面

- Supabase に接続できない / データが 1 行も無い場合の全体フォールバック
- 「データを取得できませんでした」と最終成功時刻を表示する
- 部分的な欠測は各チャートの空状態で扱い、この画面は出さない

## 共通の状態

| 状態 | 扱い |
| --- | --- |
| ローディング | チャート単位でスケルトン表示 |
| 部分欠測 (特定週) | 線を繋がない。前方補完しない (F-10) |
| 系列全体が空 (期間外) | チャート枠は残し「蓄積中 (YYYY-MM-DD 以降)」を表示 |
| 全データ取得不能 | S-3 へ |

## 画面遷移

S-1 (ルート) ⇄ S-2 (フッターリンクから)。S-3 は S-1 のフォールバック。
認証・複数ユーザーが無いため、他の遷移は無い。
