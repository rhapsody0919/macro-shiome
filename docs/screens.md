分割の基準は「見る目的」。S-1 は個別の判断材料 (割高か・業績が伴っているか)、
S-2 は実体経済、S-5 は金融環境と市場心理。

**セクションは「問い」で分ける** (#89)。「先行指標」という見出しでは何に使うか分からず、
指標が増えるほど「その他」が肥大した。「景気は減速しているか」のような問いにすると
「いつ何を見るか」がそのまま伝わる。**更新頻度と景気サイクルの分類は各チャートのバッジ**に残す
(週次と月次が同じ問いに混ざるため、頻度が分からないと「動いていない」の意味が読めない)。

## 全画面共通

### N-1 グローバルヘッダー

- **ナビゲーション**: 「バリュエーション」「マクロ指標」のタブ。現在地を明示する
- **期間フィルター** (F-6): 1 年 / 3 年 / 5 年 / 全期間のセグメント。**URL クエリ `?period=5y` に反映**し、
  画面遷移・リロード・共有リンクで選択を維持する
- **鮮度表示**: 最終更新日時。直近週が欠測なら警告バッジを出し、理由 (FactSet 休刊週 / 取得失敗) を
  区別して表示する。「古いデータを最新と誤認させない」ことが目的

### N-2 フッター (F-11)

- FRED 必須文言: `This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis.`
- 各指標の出所と著作権 (S&P Dow Jones Indices / Nasdaq, Inc. / FactSet / stockanalysis.com / FRB / CBOE)
- S-3 へのリンク、投資助言ではない旨の免責

## S-1 バリュエーション (`/`)

### C-1 サマリーバー

ページ先頭に最新値を横並びのカードで置く。チャートを読む前に現状を把握できるようにする。

- カード: 指数 / Forward P/E / イールドスプレッド / **割高率** / 直近1年の相関係数
- **指数の切り替え (S&P 500 / NASDAQ-100) をここに置き、全カードが連動する**
- 各カードに**前週比**を併記 (数値 + 上下の向き)。色だけに頼らず記号も添える
- Forward P/E カードは「5 年平均 19.9 を上回る」のように**事実として**表示する。
  「買い時」等の評価語は使わない (投資助言と受け取られないため)
- **割高率カード** (F-13) は理論値と併記し、**基準益回りの設定値を必ず表示する**
  (例: 「+3.8% / 理論値 7,453 / 基準益回り 3.67%」)。設定に依存する数値であり客観的な絶対値では
  ないため、値だけを単独で見せない。C-9 へのリンクを置く

### C-2 Chart 1: 指数 vs EPS (F-2)

左軸に指数、右軸に EPS 2 系列の二軸折れ線。

- **指数切り替え**: S&P 500 / NASDAQ-100 のトグル。切り替えは URL クエリに含めない (期間と違い共有価値が低い)
- 凡例クリックで系列の表示/非表示を切り替えられる
- ホバーで縦ガイド線 + 全系列の値を1つのツールチップにまとめる (系列ごとに別々に出さない)
- EPS は導出値 (指数 ÷ PER) である旨をチャート脇に常時表示。詳細は ⓘ ツールチップで
- **NASDAQ-100 選択時**: Forward EPS は経路が無いため凡例から消し、「NASDAQ-100 は Forward PER の
  無料取得経路が無いため Trailing のみ」と注記。Trailing PER は蓄積開始以降しか無いため、
  期間によっては「蓄積中」表示になる。**この2つを混同させない**
- **EPS 単独モード**: 指数を非表示にして EPS 2 系列だけを見られるようにする (凡例トグル)。二軸だと EPS の細かい動き (週次の改定) が潰れるため
- **過去最高値マーカー**: 各 EPS 系列が最高値を更新した週に印を打つ。ホバーで更新幅を出す。手作業で「(過去最高値)」と注記されている運用を自動化するもので、**アプリ化の価値が最も出る要素**
- **前週比**を数値で併記 (絶対値と %)。C-1 サマリーバーと整合させる
- **数値の水準は情報源により約 9% 異なる** (spec F-2 補足)。ⓘ から定義の説明に到達できるようにする
- 欠測週は線を繋がない

### C-3 Chart 2: Forward P/E と基準線 (F-3)

S&P 500 の Forward 12M P/E と 5 年平均・10 年平均の基準線。

- 基準線はグレーの破線 + ラベル (値と取得日)。**固定値ではなく毎週更新される**旨を明記
- 現在値と基準線の位置関係が一目で分かるよう、平均を超えた領域を淡く塗る
- **S&P 500 専用**。C-2 で NASDAQ-100 を選んでいても本チャートは S&P 500 のまま。誤読を避けるため
  チャート見出しに「S&P 500」と明示する
- バックフィルが 5 年分のため、「全期間」でも 5 年より前は空

### C-4 Chart 3: イールドスプレッド (F-4)

株式益回り − **実質金利**。名目金利ではない (spec F-4 の定義修正を参照)。

- ゼロ線を引き、**正負で塗り分ける**。負 = 実質金利が株式益回りを上回る局面であることを凡例で説明
- 計算式をチャート脇に明示: 株式益回り = 1 ÷ Forward P/E × 100、**実質金利 = 10 年債 − 期待インフレ率**
- 内訳 (株式益回り / 名目 10 年債 / 期待インフレ率 / 実質金利) は既定で非表示、凡例トグルで出せる
  ようにする。スプレッドの動きが株式側・金利側・インフレ期待側のどれ由来かを判別するため
- S&P 500 / NASDAQ-100 を切り替えられる (C-1 の切り替えに連動)
- 単位は % に統一。Forward P/E が欠測の週は線を繋がない

### C-9 理論値と割高率 (F-13)

**「割安か・適正か・割高か」を示す画面の中核**。

- 理論値 (= 実績 EPS ÷ 基準益回り) と実際の指数を**同一チャートに重ねる**。乖離が視覚的に分かる
- 割高率の推移を別系列で表示。ゼロ線を引き正負で塗り分ける
- **基準益回りを画面から変更できる**。変更すると理論値・割高率が即座に再計算される
- 基準益回りの**変更履歴**を表示する (いつ・いくつに・なぜ)。成長率の前提が変われば見直す値のため
- **この数値は基準益回りの設定に依存する**旨を常時表示する。客観的な絶対値ではない
- 初期値 (S&P 500 = 3.67% / NASDAQ-100 = 3.27%) の根拠を ⓘ で説明する (spec F-13)
- **理論値は週の途中で動かない**。実績 EPS が週次更新のため、週内は理論値が横ばいで**割高率だけが
  指数の変動で動く**。これは正常な挙動なので、「更新されていない」と誤解されないよう
  理論値に「実績 EPS の更新日」を併記する

### C-5 相関サマリー Card (F-5)

S&P 500 指数と Forward 12M EPS の相関係数。

- 直近半年 / 直近 1 年 / 全期間の 3 つを並べ、各期間の標本数 n を併記
- 相関の強さをバーで視覚化する (−1〜+1 のスケール上に位置を示す)
- **この Card だけは期間フィルターに追従しない**。3 期間の比較自体が目的のため。
  画面上に「期間フィルターの対象外」と明記する
- n < 10 の期間は数値を出さず「データ不足 (n=X)」。全期間が n < 10 なら Card 全体を「蓄積中」に

### C-6 予想改定チャート (F-12)

アナリスト予想が先週・先月より上がっているか。**本アプリの主目的の 1 つ**なので S-1 に置く。

- **今週 / 先週 / 四半期末**の 3 時点を並べた比較 (進行中四半期の blended 成長率)。
  FactSet PDF 本文に毎週明記されるため、蓄積ゼロの初週から表示できる
- CY2026 / CY2027 の予想成長率の週次推移を折れ線で。**バックフィルにより初日から 5 年分出せる**
- 前週差をポイントで併記し、符号を明示 (上昇 = 上方修正)
- **forward 12M EPS の推移と並べない**。forward 12M はロールで上昇バイアス (週約 0.3%) を持ち、
  改定と混同されるため。同じ画面に出す場合は「ロール込み」「純粋な改定」のラベルで区別する
- 売上成長率も同形式で表示 (P2、既定は折りたたみ)

### C-7 VIX / USDJPY / 10 年債利回り (F-7)

- 週次チャートより点が粗いことが視覚的に分かるよう、マーカーを打つ

## S-3 利用規約・出所 (`/terms`)

FRED 規約が「他ユーザー向けアプリ」に課す義務を満たすための静的ページ (F-11)。

- FRED API Terms of Use へのリンクと「本アプリの利用により FRED API 規約に同意したことになる」旨
- 各データソースの出所・著作権・利用条件。stockanalysis.com は出所明記が利用条件
- **EPS / PER が as-reported (GAAP) ベースである旨**と、一般的な投資レポート (operating ベース) とは
  約 9% ずれる説明。**誤読リスクが高いため、フッターだけでなく EPS / PER を表示する各チャートの
  ⓘ ツールチップからも同じ説明に到達できるようにする**
- NASDAQ-100 の PER は ETF (QQQ) 由来で指数そのものの PER と厳密には一致しない旨
- 権利者からの要請時に系列単位で公開停止する運用方針 (spec U-8)
- 文面は U-S2 で未確定

## UI/UX の方針

チャートが主役の画面なので、以下を全体の設計方針とする。

1. **数値の誤読を防ぐことを最優先**。EPS が導出値であること、PER が as-reported ベースであること、
   NASDAQ の PER が ETF 由来であることは、いずれも黙っていると誤解を生む。ツールチップに逃がしつつ、
   最低限の注記は常時表示する
2. **評価語を使わない**。「割高」「買い時」ではなく「5 年平均を上回る」と事実で書く (免責の実効性のため)
3. **色だけに情報を載せない**。前週比の上下は色 + 記号、系列は色 + 凡例ラベルで区別する
4. **欠測を隠さない**。線を繋いで滑らかに見せるより、欠けていることが分かる方が正しい
5. **期間フィルターは URL に載せる**。共有・リロードで状態が飛ばない
6. **モバイルでは二軸チャートを縦2枚に分割する**。二軸は狭い画面で潰れて誤読を招くため、
   指数と EPS を別チャートにして縦に並べる (spec 4 節はスマホを「閲覧できれば可」としているが、
   二軸だけは分割が必要)
