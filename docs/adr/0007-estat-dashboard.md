# ADR-0007: 日本の経済指標は統計ダッシュボード API から取る

- ステータス: 採用
- 日付: 2026-08-19
- 関連: #129 / ADR-0006 (米財務省)

## 背景

日本の経済指標、とくに住宅市場を macro-shiome に取り込みたいという要望が出た。

## FRED では取れない

系列ページのタイトルと CSV の最終行を一次情報として 20 系列を確認した。

| 系列 | 状況 |
| --- | --- |
| `HOUSTJP` | **存在しない**。CSV は 546 行返るが中身はエラーページの HTML |
| `JPNPERMITMISMEI` (住宅着工許可) | **DISCONTINUED**、最終 2008-05 |
| `WSCNDW01JPQ657S` (住宅着工) | 四半期、最終 2023-07 |
| `JPNCPIALLMINMEI` ほか CPI 4 種 | すべて **2021-06 で停止** |
| `JPNPROINDMISMEI` (鉱工業生産) | 2024-03 で停止 |
| `BSCICP03JPM665S` / `CSCICP03JPM665S` (景況感) | 2023-12 / 2024-01 で停止 |

現行なのは失業率・輸出入額・10年債利回り・実質実効為替・実質 GDP の 6 系列のみで、**住宅は無い**。

**行数だけで存在を判定してはいけない。** `HOUSTJP` はその実例で、#66 (`RSCCASN` を別物と取り違えかけた) と同じ型の失敗になるところだった。

## 候補の比較

| 案 | 無料 | 登録 | 住宅着工 | 運用負荷 | 不適合点 |
| --- | --- | --- | --- | --- | --- |
| **統計ダッシュボード API** | ○ | **不要** | ○ | 低 | 収録は約 6,000 系列に限られ、詳細表は無い |
| e-Stat 統計 API | ○ | **appId 必須** | ○ | 中 | Secrets の管理が増える。公開リポなので露出リスクを持ち込む |
| 日本銀行 時系列統計 | ○ | 不要 | **×** | 中 | 金融統計が中心で住宅は対象外 |
| 各省庁の Excel 直取り | ○ | 不要 | ○ | **高** | 様式変更で毎回壊れる。#4 の PDF 抽出と同じ問題を増やす |

## 決定

**統計ダッシュボード API (`dashboard.e-stat.go.jp`) を 6 つ目のデータソースにする。**

`api.e-stat.go.jp` (統計 API) とは別物で、公式に登録不要と明記されている。

> This API is available to everyone without registration
> — https://dashboard.e-stat.go.jp/static/api

**キーを持ち込まないことを重視した。** 本リポジトリは公開で、秘密情報を増やすほど露出面が広がる。ダッシュボードで足りるうちはこちらを使う。

## 落とし穴 (実装で必ず踏む)

**1 回のレスポンスに複数の系列が混ざる。** 新設住宅着工戸数 (総戸数) の例:

| 属性 | 内訳 |
| --- | --- |
| `@cycle` | 月次 1,044 / 四半期 174 / 年 43 / 年度 43 |
| `@isSeasonal` | 原数値 608 / 季調値 696 |

`cycle` と `isSeasonal` の**両方**を固定しないと、同じ `@time` に 2 つ値が返る。#96 (10年債入札に TIPS が混入) と同じ型。

メタ情報で確定した意味 (推測ではない):

```
cycle:         1 = 月
isSeasonal:    1 = 原数値 / 2 = 季調値
isProvisional: 0 = 確報
```

日付は `YYYYMM00`。年度は `2025FY00` の形で混ざるため、**形式でも弾く**。`cycle` の絞り込みと二重にする。

## 単位

新設住宅着工戸数は**戸**。米国の `HOUST` は**千戸**。定義 (季節調整済み年率換算) は同じだが単位が違うので**同じ図に載せない** (#116〜#118 の「重ねずに切り替える」)。

内訳 (持家・貸家) は**年率換算していない季調値**なので、総戸数とも水準が 1 桁違う。内訳どうしだけを並べる。

## 将来

e-Stat 統計 API (appId 必須) はダッシュボードに無い詳細表が要るときに検討する。その場合は `ESTAT_APP_ID` を GitHub Actions Secrets に置く。**コード・ログ・コミットには残さない** (FRED / Finnhub と同じ扱い)。
