# ADR (Architecture Decision Record)

重要な技術判断は 1 判断 = 1 ファイルで残す。ファイル名は `NNNN-kebab-case-title.md` (連番)。

書式:

```
# NNNN. タイトル

- ステータス: 提案 / 採用 / 棄却 / 置換 (置換の場合は置換先 ADR 番号)
- 日付: YYYY-MM-DD
- 関連: #Issue番号

## 背景

## 検討した選択肢

| 評価軸 | 案A | 案B |
| --- | --- | --- |

各案の不適合点を明示する。

## 決定

## 理由

## 影響・トレードオフ
```

まだ ADR は無い。最初の判断は SDD Step 2 (`/step2`) で技術スタックを選定するときに発生する。
